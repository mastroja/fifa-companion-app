- [ ] **Awards tracking** — MOTM, POTM, POTS, Ballon d'Or. *(Under active investigation, 2026-09-12 — reassessed, easier than first thought for MOTM/POTM:*
  - *Live Editor does expose a real per-competition-per-season `motm` (Man of the Match count) field, confirmed in its bundled `export_season_stats.lua` reference script and `DOC.MD` — same data category as goals/assists/yellow/red the app already imports. Docs flag it `(not sure if data is correct)`, so spot-check a known player's count before relying on it.*
  - *That field alone only supports a season-total "Most MOTM awards" honor (same pattern as existing Golden Boot/Playmaker/Golden Glove) — it has no date/match attached, so it can't directly give month-by-month POTM.*
  - *Proposed workaround for monthly POTM (diff-based, needs no new Live Editor data): store each player's MOTM count on every refresh/import, and when it increases, attribute the award to the most recent match(es) played since the last refresh (dates already available from calendar/match data). Rule of thumb floated: 2+ MOTM in a month = Player of the Month. Works cleanly when refreshing close to game time (the common case, especially with auto-refresh). Edge case resolved: if the user sims many days/weeks without refreshing and a count jump can't be pinned to a single month, just skip assigning POTM for that stretch rather than guessing — no award is better than a wrong one.*
  - *POTS/Ballon d'Or (real-world awards) — still being searched for an in-game source (world player of the year / league player of the year exist in-game per the user). If none is found, manual entry via the existing `world_league_awards` pattern is the fallback.*
  - *No per-match player data exists anywhere else (see Per-game stats below) — the MOTM diffing approach above is the one path that sidesteps that gap.*
  - **Sub-task: build our own Player of the Year value, if not tracked in-game.** Composite score from season-cumulative stats: # of MOTM, # of goals, # of assists, # of clean sheets (GKs/Defenders/CDMs only), average match rating. **POTM deliberately excluded** — it's arithmetically derived from MOTM (2+ MOTM in a month), so including both would double-count the same underlying signal; MOTM alone represents it.
    - *Design goal, 2026-09-12: these awards naturally skew toward attacking players (goals/assists only exist for them), so the formula should be built to still give defensive/midfield players a real chance rather than locking POTY to strikers by default.*
    - **Final weights, locked in 2026-09-12: MOTM 30% / Average rating 30% / Goals+Assists 25% / Clean sheet rate 15%.** Revised up from an initial 40/20/25/15 rating-heavy split after testing against made-up sample data showed match ratings cluster too tightly across players (e.g. 7.3–7.9) to meaningfully separate a season's best from the rest — MOTM and G+A vary more and do more actual differentiating work. Bumping MOTM specifically (rather than G+A) to reach parity with rating was chosen deliberately because MOTM is a stat every position can earn, unlike goals/assists — validated against the sample data below, where the goalkeeper's rank rose from last-place-adjacent up to mid-table once MOTM carried equal weight to rating.
    - *Normalizing counting stats (MOTM/goals/assists/clean sheets) by appearances or per-90 rather than using raw totals is the key lever for fairness across positions — raw counts alone would still hand it to whichever attacker played every match.*
    - *Scoring mechanics: each component is converted to a fixed 0–100 scale (not relative to the season's field, so scores stay comparable year to year) before weighting: rating → `(rating/10) × weight`; MOTM → `min(MOTM/Apps ÷ 0.5, 1) × weight` (50% MOTM rate = ceiling); Goals+Assists → `min((G+A)/Apps ÷ 1.0, 1) × weight` (1 contribution/game = ceiling); Clean sheets → `(CS/Apps) × weight`, 0 for non-GK/DEF/CDM. Sum of all four = final 0–100 POTY score.*
    - *Validated 2026-09-12 against a made-up 10-player/38-game sample (3 ST, 3 W, 2 CM, 1 RB, 1 GK): 2 players failed the 70% appearance gate and were excluded; of the 8 eligible, final ranking was Striker (62.0) > Winger (56.1) > Striker (49.4) > Winger (48.6) > Goalkeeper (46.6) > Center Mid (46.3) > Right Back (44.4) > Center Mid (40.1) — the striker still wins (deservedly, on a 28-goal season), but the goalkeeper landing above a center mid confirms the formula gives non-attacking positions a real shot rather than being structurally locked out.*
    - **Eligibility gate, decided 2026-09-12: minimum 70% of the season's matches appeared in to qualify for POTY.** Needed because rate-based normalization (above) is blind to sample size — without a threshold, a player with a handful of appearances and a flawless rate could outscore a full-season starter. Below 70% appearances, a player isn't considered for POTY regardless of composite score.*
